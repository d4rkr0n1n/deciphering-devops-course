## Commands
- `cd` - Change Directory
- `ls` - List Files and Directories
- `pwd` - Print Working Directory
- `cp` - Copy Files and Directories
- `mv` - Move Files and Directories
- `rm` - Remove Files and Directories
- `mkdir` - Create Directories
- `cat` - Concatenate one or multiple files and print their contents directly
- `less` - Utility used to view the contents of a text file or command output
- `grep` - Global Regular Expression Print | search for specific words, phrases, or patterns
- `find` - used to search for files and directories within a file system hierarchy

## Important Directories
- `/etc` - contains system-wide configuration files
- `/var` - stores data that changes while the system is running
- `/home` - contains the personal directories of normal Linux users
- `/tmp` - shared location for temporary files created by applications and users
- `/opt` - is commonly used for self-contained optional or third-party applications

### TL;DR
- `/etc` → Configure it
- `/var` → Changing/runtime data
- `/home` → User owns it
- `/tmp` → Throw it away later
- `/opt` → Optional/custom software
