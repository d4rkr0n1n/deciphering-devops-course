# Deciphering DevOps Course

Master DevOps with Vagrant, Docker, Kubernetes, GitHub Actions, ArgoCD, GitOps, Terraform, Monitoring, and AI.

## What You'll Learn
- Learn DevOps from scratch
- Linux and server management with Gemini CLI
- Networking fundamentals and Vagrant-based environments
- YAML, JSON, and Bash scripting with GitHub Copilot
- Local infrastructure with Vagrant, VirtualBox, provisioning, networking, and multi-machine setups
- Build and test automation using Git, Maven, Jenkins, GitHub Actions, and GitLab CI/CD
- CI/CD projects with Nexus, SonarQube, and Slack integration
- Python automation with OpenAI ChatGPT AI assistance
- Infrastructure as Code using Terraform, modules, and remote-state concepts
- Configuration management using Ansible
- Monitoring and observability with Prometheus, Grafana, Loki, Alertmanager, and Alloy
- Docker, Kubernetes, Helm, Lens, and production-style deployments
- GitOps: GitHub Actions, Kubernetes, Helm, and ArgoCD

## Requirements
- Basic computer knowledge
- A computer capable of running local virtual machines
- Vagrant and a supported provider such as VirtualBox

## Description
This course takes you from DevOps beginner to job-ready DevOps Engineer through hands-on projects, reproducible local infrastructure, CI/CD pipelines, Kubernetes, GitOps, monitoring, observability, and AI-powered automation.

You will build and deploy applications in Vagrant-based multi-VM environments, Docker, Kubernetes, and GitOps workflows while learning the tools and practices used by modern DevOps teams. Vagrant provides a consistent way to define, create, and share development and test environments without relying on a public-cloud account.
